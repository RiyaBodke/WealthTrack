## Features

- User Authentication
- Portfolio Tracking
- Stock Management
- Admin Dashboard
- Portfolio Analytics
- Performance Charts
- Client Management

## Tech Stack

Frontend:
- React
- Tailwind CSS
- Recharts

Backend:
- Node.js
- Express.js

Database:
- PostgreSQL

## Installation

Frontend:

npm install
npm run dev

Backend:

npm install
npm run dev
