# Contributing to WealthTrack

Thanks for your interest in contributing!

## Getting started
1. Fork the repository and clone your fork
2. Follow the setup steps in the [README](README.md)
3. Create a branch: `git checkout -b feature/your-feature-name`

## Making changes
- Keep changes focused on one feature or fix
- Follow the existing code style
- Test your changes locally with both an admin and a client login
- Never commit `.env` files or real credentials

## Submitting
1. Push your branch and open a pull request
2. Describe what you changed and why
3. Link the related issue, if there is one

## Reporting bugs or suggesting features
Open an issue and include steps to reproduce, expected behaviour and screenshots where possible.
